## 如何使用历史证据

历史行号、模型数量、素材状态和建议可能已变化。报告中的 CONFIRMED 表示当时复核成立，不表示当前仍有缺陷；DISMISSED 的理由也保留为参考。未逐项维护修复状态时，不能将报告视为当前缺陷清单或完整验收结论。

本轮文档整理未重新执行这些历史用例。当前能力与验证边界见 [STATUS](../../STATUS.md)；实现规则见[开发文档](../dev/README.md)；设计意图见[设计资料](design/README.md)。

卡牌目录已重新收纳。历史报告中的旧路径和行号保留调查时含义；当前路径按[卡牌目录组织](design/card-organization.md)定位，可用 `rg --files src/STS2-Navia/Content/Cards` 按类名查找。

案例记录现象、根因、修复和防止再次发生的约束。新的历史记录注明对应游戏／依赖版本与证据类型；将稳定结论同步到所属现行手册，保留可理解的演变背景。
