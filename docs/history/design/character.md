# 角色与核心机制（原案）

公开整理于 2026-09-30。原案未标注版本日期；本文保留原始设计的数值与叙事，只调整排版。当前实现及已确认差异见[设计与实现对照](implementation-notes.md)。

## 娜维娅

——来自白淞镇的刺玫会长，用铳弹与礼炮扫平一切障碍。

初始生命值：75

## 初始遗物：刺玫会徽

每回合你第一次获得格挡时，装填1。

## 进阶遗物：仅留余香的野蔷薇

战斗开始时，装填３。每回合你第一次获得格挡时，装填１。

## 特殊BUFF.装填（最大值：6）

每有2层装填，获得1点临时敏捷。某些卡牌可以消耗装填层数以获得额外的效果。

## 特殊机制：礼炮轰鸣

在手牌中生成一张金花礼炮。若手中已有金花礼炮，则使手牌中所有的金花礼炮伤害提升等量于礼炮轰鸣的值。

## 相关token

**\[金花礼炮]**（攻击）（1）（无色卡）：造成2点伤害3次。消耗。

**\[闪耀摩拉]**（攻击）（0）（无色卡）：造成3点伤害。消耗。每打出3张\[闪耀摩拉]，装填１。保留。
