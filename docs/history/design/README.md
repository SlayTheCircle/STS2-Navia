# 设计原案与技术历史

本目录保存设计过程性记录：设计者提供的原案整理（保留原始数值与叙事）、已核对的设计与实现差异日志、已采纳的方案评估。它们记录设计演变，当前设计与实现见现行手册和 STATUS。

当前确定性设计体系见[设计资料](../../design/README.md)：现行卡表由脚本从源码与本地化生成；数量、验收与限制由 [STATUS](../../../STATUS.md) 维护。
