## 贡献方式

定版前多媒体不提交到 Git / LFS。先提出资源槽、构图、来源与预期画面的说明，再按维护者确认的交付方式提供母版；正式素材授权与公开分发方式仍待决定。使用生图工具补图时，现有同系列素材应作为视觉参考；记录提示词、参考图、来源与生成结果，保留既有原件。

文字规格、映射与生成代码可通过源码贡献维护。母版位置通过 ART_SOURCE_DIR 配置，普通输出路径相对 assets/STS2-Navia/，纪元大图使用 assets/global/。修改输入映射时同步更新派生脚本和资源使用方，再检查静态图窗与大／小图动效槽。完整素材与 PCK 检查不能代替游戏内验收。
