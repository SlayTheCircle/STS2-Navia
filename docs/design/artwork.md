## 局内角色骨骼动画

角色采用 **imagegen 辅助拆件与补画 + Godot 原生骨骼动画**。交付为可编辑美术母版、透明零件及 Godot 场景／动画资源。商店、休息点与选人资产分别维护。

先定完整角色的脸、身材比例、服饰与持伞姿态，再从同一母图拆件。生成工具提供像素素材；部件坐标、关节、层级、网格、权重和关键帧由本地组装与校准负责。不以一次生成的零件表作为精确可拼合的保证。可用像素优先保留，被遮挡的肩肘、腰侧、发束及衣服区域定向补画；手型与表情可以使用局部替换附件，身体动作应连续驱动。

验收按以下顺序推进，每一步保留可对照成果：

1. 完整母图：角色辨识度、画风、比例、武器结构与战斗小尺寸可读性。
2. 静态重组：与母图并排比较，不因拆分破坏脸型、服饰轮廓、光照或握持关系。
3. 小范围动作：先做呼吸、眨眼、发尾摆动及抬伞；检查关节露洞、脚底滑动、手与武器分离及变形失真。
4. 完整动作：覆盖待机、攻击、施法／能力、受击、死亡、低血量与放松；再验证复活、翻转、连续出牌和双版本游戏接线。

技术样件与美术验收分开：技术样件检查组装与播放，正式画风的动态效果通过正常速度、慢放和游戏内画面确认。贡献者无需操作付费动画编辑器；审核以静态对照、正常速度／慢速动画及游戏内画面为依据。实现与证据边界见 [STATUS](../../STATUS.md)，资源组织见[素材规范](../dev/assets.md#角色骨骼资源)。

## 贡献方式

定版前多媒体不提交到 Git / LFS。先提出资源槽、构图、来源与预期画面的说明，再按维护者确认的交付方式提供母版；素材按现行限定授权与发行边界交付，见 [素材规范](../dev/assets.md)。使用生图工具补图时，现有同系列素材应作为视觉参考；记录提示词、参考图、来源与生成结果，保留既有原件。

文字规格、映射与生成代码可通过源码贡献维护。母版位置通过 ART_SOURCE_DIR 配置，普通输出路径相对 assets/STS2-Navia/，纪元大图使用 assets/global/。修改输入映射时同步更新派生脚本和资源使用方，再检查静态图窗与大／小图动效槽。最后在游戏中确认显示效果。

局内系列动画的长期精修方向见 [backlog #1](https://github.com/SlayTheCircle/STS2-Navia/issues/1)，优先考虑死亡动作的重心、关节、落地缓冲与动作衔接；无排期或完成承诺。当前实现与验收范围仍以 [STATUS](../../STATUS.md) 为准。
