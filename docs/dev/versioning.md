# 版本与兼容约定

[STS2-Navia.json](../../STS2-Navia.json) 的 version 是模组版本唯一来源。构建复制原清单；新生成发行 ZIP 从该字段命名，包内清单、发布说明和 tag 使用同一版本。正式版本确定由维护者决定。

模组版本与游戏版本独立维护。RITSULIB_TARGET 选择与游戏引用一致的 compat 版本；0.111.0 已发行，0.107.1 编译已通（条件编译吸收差异），游戏内验收与变体发行待做。游戏／依赖升级涉及钩子、注册、资源、存档或部署变化时，发布说明列出影响和必要操作。

版本采用三段式；开发候选和预发布标识是否被游戏加载器与版本比较正确消费，需要先验证后启用。当前不因建立规范而自动修改清单版本，不对历史内部包追溯改号。历史包文件名与清单不一致作为内部遗留记录，由私有索引保存。

发布 tag 使用 v 前缀，清单不带 v。打 tag 前冻结版本与验收范围，不覆盖已公开 tag 或发行包。双版本发布需要两个分别编译和验收的变体，不能只改 min_game_version 声称兼容。
