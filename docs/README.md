## 贡献者模块

| 模块 | 内容 |
|---|---|
| [设计资料](design/README.md) | 原始设计稿、卡表、升级参考、叙事、实现差异与美术贡献需求 |

现行规则与历史记录有各自的适用范围；原案注明设计意图和实现差异，历史审计注明调查时间与版本。维护职责见[文档与仓库边界](dev/documentation.md)。

本机工作区可经私有入口 `local_dev/README.md` 导航；该目录整体不随仓库分发。公开设计与工程说明无需取得其中的原件。
